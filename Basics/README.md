# Basics

## What is DSA?

DSA stands for **Data Structures and Algorithms**.

- **Data Structures** help in organizing and managing data efficiently.
- **Algorithms** are step-by-step instructions used to solve a particular problem.

Together, DSA helps us write optimized and efficient programs.

---

## Why Learn DSA?

DSA is one of the most important skills in Software Development.

### Benefits of Learning DSA

- Improves problem-solving skills
- Helps write memory-efficient programs
- Helps optimize time complexity
- Builds logical thinking
- Used heavily in technical interviews
- Forms the foundation of software engineering

---

## Programming Fundamentals

Before learning advanced DSA concepts, it is important to understand programming fundamentals.

---

### 1. Variables

Variables are containers used to store data values.

### JavaScript

```js
let name = "Yathe";
let age = 22;
```

### Python

```py
name = "Yathe"
age = 22
```

---

### 2. Syntax

Every programming language follows a specific syntax.

Although many programming languages are similar, each language has its own rules and structure.

#### Keywords

Keywords are predefined reserved words that have special meanings.

Examples:
- `if`
- `else`
- `for`
- `while`
- `return`

---

### 3. Data Types

Data types represent the classification of data.

#### Common Data Types

| Data Type | Example |
|-----------|----------|
| String | `"Hello"` |
| Number | `10`, `3.14` |
| Boolean | `true`, `false` |
| Undefined | `undefined` |
| Null | `null` |

---

#### Why Are Data Types Important?

Data types help in:
- Better memory management
- Efficient storage
- Faster processing

---

#### Data Types vs Data Structures

| Data Types | Data Structures |
|------------|----------------|
| Represents a single value type | Organizes multiple values |
| Example: Number, String | Example: Array, Stack, Queue |

---

### 4. Constraints

Constraints are restrictions or limitations given in a problem statement.

They help us:
- Choose the correct algorithm
- Decide suitable data types
- Optimize the solution

#### Example

```txt
The array contains less than 10^6 elements
```

This tells us:
- Input size is large
- Efficient solutions are required

---

### 5. Debugging

Debugging is the process of:
- Finding bugs/errors
- Fixing issues in the program

It is one of the most important programming skills.

---

### 6. Conditionals

Conditionals help in decision-making.

---

#### if-else Statement

#### JavaScript

```js
if(condition) {
    // code
} else {
    // code
}
```

#### Python

```py
if condition:
    # code
else:
    # code
```

---

### else-if Ladder

#### JavaScript

```js
if(condition1) {
    // code
} else if(condition2) {
    // code
} else {
    // code
}
```

#### Python

```py
if condition1:
    # code
elif condition2:
    # code
else:
    # code
```

---

### 7. Loops

Loops help in repeating a block of code multiple times.

---

#### for Loop

#### JavaScript

```js
for(let i = 0; i < 5; i++) {
    console.log(i);
}
```

#### Python

```py
for i in range(5):
    print(i)
```

---

#### while Loop

#### JavaScript

```js
let i = 0;

while(i < 5) {
    console.log(i);
    i++;
}
```

#### Python

```py
i = 0

while i < 5:
    print(i)
    i += 1
```

---

### 8. Break and Continue

#### Break

Stops the loop completely.

---

#### Continue

Skips the current iteration and moves to the next iteration.
