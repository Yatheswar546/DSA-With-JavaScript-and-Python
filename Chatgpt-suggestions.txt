# Folder Naming Recommendation

Use numbering:
```txt
01-
02-
03-
````

Why?
Because GitHub sorts folders alphabetically.

Without numbering:

```txt
Arrays
Basics
Graphs
LinkedList
```

becomes messy.

# Code File Naming Recommendation

Keep filenames problem-oriented.

Example:

```txt
reverse-array.js
reverse-array.py

kadane-algorithm.js
kadane-algorithm.py
```

Avoid:

```txt
program1.js
test.py
final.py
```
